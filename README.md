One line, 65 characters, written to `/output/entry.txt`:

> I sneezed so hard my back filed a workers' comp claim against me.

Why this line: a hard sneeze really can throw a back out, so a boss might
half believe it — and the back answering the way an employee would, by
filing a workers' comp claim, is the laugh, landing on the last two words.
No fever, no dog, no dead grandmother; it reads like a real message, and
every word is doing work.

## Run it

```sh
python3 main.py
```

The program is fully deterministic: it writes the same fixed line on every
run, with no network, randomness, or clock reads, so two runs in the
grader's sandbox produce byte-identical output.
